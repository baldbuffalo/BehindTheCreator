# BehindTheCreator

BehindTheCreator is a native Kotlin Android app that turns YouTube creators into an encyclopedia of stories and lesser-known facts.

## Current version

- Creator list with profiles
- Creator detail pages
- Career/story summaries
- Lesser-known-facts section
- Material 3 Compose UI
- Native Kotlin Android project

## Roadmap

- Real creator profile pictures
- Search and categories
- Source links for every fact
- More creators
- Timeline of major career moments
- Favorites/bookmarks
- Offline creator database
- Automated APK builds

## Build

Open the project in Android Studio and run the `app` configuration. The project uses Kotlin, Jetpack Compose and Gradle.
